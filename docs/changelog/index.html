1.0.0 - 2026-09-20¶

Docs | Playground

🎉 djangofmt 1.0 is here! The formatter is now stable, hardened by extensive fuzzing, ecosystem check and bug fixing. The new check command also gained automatic Tailwind CSS class sorting, powered by rustywind.
